## 🎨 Creative AI

> Audience: practitioners · Evidence class: mixed

Descriptions in this appendix prioritise workflow characteristics and deployment constraints over superlatives or leaderboard language.

### Image Generation

| Tool | Description |
|------|------------- |
| [Midjourney v7](https://midjourney.com) | Strong stylistic control with Discord and web-based image workflows. |
| [DALL-E 3.5](https://openai.com/dall-e) | ChatGPT-integrated image generation with reliable prompt following and text rendering. |
| [FLUX 2](https://blackforestlabs.ai) | Open-weight image models aimed at photorealistic output and flexible deployment. |
| [Stable Diffusion 3.5](https://stability.ai) | Open-source. ControlNet, LoRAs, ComfyUI ecosystem. |
| [Adobe Firefly 3](https://firefly.adobe.com) | Licensed data only. Commercial indemnification. Photoshop. |
| [Google Imagen 4](https://deepmind.google) | Photorealistic image generation exposed through Google's AI tooling. |
| [Ideogram v3](https://ideogram.ai) | Strong text rendering for logos, posters, and design-heavy image outputs. |
| [Leonardo AI](https://leonardo.ai) | Multi-model. Realtime Canvas. 3D gaming assets. Canva-owned. |
| [Recraft](https://recraft.ai) | Design-focused. Vector art, brand consistency. |

### Video Generation

| Tool | Description |
|------|------------- |
| [Sora 2](https://sora.com) | Video generation focused on longer-form scene consistency and motion realism. |
| [Google Veo 3.1](https://deepmind.google) | High-fidelity video generation with native audio and Vertex AI integration. |
| [Runway Gen-4.5](https://runwayml.com) | Video generation and editing suite with motion-directed controls. |
| [Kling 3.0](https://klingai.com) | Longer-form 4K video generation with API access and native audio. |
| [Seedance 2.0](https://seedance.ai) | Quad-modal input. Lip sync. 2K resolution. |
| [Pika 2.5](https://pika.art) | Beginner-friendly. Pikaswaps. Fast renders. |
| [Luma Dream Machine](https://lumalabs.ai) | 4K HDR. Physics simulation. 3D/cinematic. |
| [HaiLuo AI](https://hailuoai.video) | Budget video. 10 free/day. MiniMax. |
| [Wan 2.1](https://github.com/Wan-Video/Wan2.1) | Open-source video generation model suitable for self-hosted experimentation. |
| [HunyuanVideo](https://github.com/Tencent/HunyuanVideo) | Tencent OSS. Consumer GPU. Multi-style. |
| [LTX Video](https://github.com/Lightricks/LTX-Video) | OSS. Licensed data. Clear commercial terms. |
| [Rea Video](https://reavideo.video/) | Browser tool that analyses a clip locally, without upload, to find cuts, extract reference frames and export a shot-by-shot prompt pack for AI video. Accepts MP4 or WebM up to 3 minutes and 300 MB. |
| [OpenMontage](https://github.com/OpenMontageInc/OpenMontage) | AGPL-3.0 agentic video production system with 12 pipelines defined as YAML manifests and Markdown skill files, run by a coding assistant such as Claude Code, Cursor, Copilot, Codex or Windsurf. Includes approval gates and a default budget cap; several features need paid provider keys. |
| [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) | Short-video generator that turns a topic into a script, footage, subtitles and background music, through a WebUI, API, CLI or an agent workflow driven by a `SKILL.md`. Cloud LLM, footage and TTS services need API keys. |
| [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | Apache-2.0 skill for Claude Code and Codex that captures a product's real pages, storyboards a film from a library of Remotion motion recipes, adds beat-synced sound design, checks rendered frames and exports an editable MP4. Frames are drawn in code rather than generated by a video model. |
| [anything2explainer](https://github.com/Vincentwei1021/anything2explainer) | Skill for Claude Code and Codex that turns a topic into a narrated explainer video drawn in code with Remotion, with TTS voiceover, subtitles and quantitative QC. Documents a multi-agent protocol in which parallel build agents write one component per shot and QC agents review rendered frames. PolyForm Noncommercial 1.0.0 licence; one film takes roughly 1 to 3 hours. |

### 3D and Design

| Tool | Description |
|------|------------- |
| [Meshy](https://meshy.ai) | Text/image to 3D. Game assets, products. |
| [Tripo AI](https://tripo3d.ai) | Fast 3D from text/images. Multi-format export. |
| [Vizcom](https://vizcom.ai) | Real-time AI rendering for industrial designers. |
| [img2threejs](https://github.com/img2threejs/img2threejs) | Agent skill that rebuilds the object in a reference image as a code-only, procedural Three.js model. Runs in Claude Code, Codex, OpenCode and Hermes. |
| [Impeccable](https://impeccable.style/) | Open-source design skill and slash commands for coding agents, with a CLI detector that flags common AI-generated UI defaults. Supports Claude Code, Cursor, Codex, Gemini CLI and GitHub Copilot. |
| [Kimi 3D Make](https://www.kimi.ai/make3d) | Browser tool that generates interactive 3D websites and games, 3D models and print-ready files for 3D printing. |
| [Astryx](https://astryx.atmeta.com/) | Open-source React design system with customizable themes, described by its docs as agent ready. Beta; built on React 19+ and StyleX. |
| [Napkin AI](https://www.napkin.ai/) | Text-to-visual tool that generates diagrams, flowcharts, mind maps and charts from pasted text, with an API for automated generation. Slides feature is in beta. |
| [Anime.js](https://animejs.com/) | JavaScript animation library for CSS, SVG and DOM animation, with timeline, scroll observer and draggable APIs. Not AI-specific. |
| [Zookeeper (Zoo)](https://zoo.dev/zookeeper) | Conversational CAD agent in Zoo Design Studio that generates CAD files from text prompts, using engine-level tools to inspect, snapshot and debug geometry. Generated models import into other CAD programs. |
| [Things Workshop](https://www.things-workshop.com/explore/) | Collection of interactive 3D models of machines and everyday mechanisms, each with an explanation and sources. |
| [CityRT](https://cityrt.com/en/) | Free browser city-building game with roads, districts, schools, hospitals and a city budget, playable solo or online. |
